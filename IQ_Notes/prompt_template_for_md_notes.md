# Prompt Template for Concept Notes

Use this prompt and replace the topic with your own question:

```text
Create a simple and clear markdown note explaining the concept of [TOPIC].

Requirements:
- Use beginner-friendly language.
- Keep the explanation short and easy to understand.
- Include a heading with the topic name.
- Add 3 sections:
  1. Definition
  2. Simple Explanation
  3. Example
- Add a small comparison table if needed.
- Write it as a markdown file in the folder IQ_Notes.
- The file name should be in this format: [TOPIC]_concept.md
- Keep the tone educational and simple.

Example:

## Example Output Style

```md
# Arrays in JavaScript

## Definition
An array is a collection of values stored in one variable.

## Simple Explanation
Arrays help us store multiple items together, such as names, numbers, or colors.

## Example
```js
let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[0]);
```
